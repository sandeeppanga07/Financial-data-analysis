# Financial Data Analysis Dashboard (Power BI)

## Project Overview

The Financial Data Analysis Dashboard is an interactive Power BI project designed to analyze and visualize the financial performance of multiple companies. The dashboard provides insights into key financial statements, including the Income Statement, Balance Sheet, and Cash Flow Statement, enabling users to evaluate company performance, profitability, liquidity, and financial stability.

This project transforms raw financial data into meaningful business insights through interactive visualizations, DAX measures, and dynamic filtering.

## Project Objectives

- Analyze annual and quarterly financial performance.
- Compare revenue, net income, assets, liabilities, and cash flow across companies.
- Identify top-performing companies based on financial KPIs.
- Monitor profitability, liquidity, and financial health over time.
- Enable interactive business analysis using Power BI dashboards.
